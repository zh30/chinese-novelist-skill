# 小说质量门控：证据而非分数

> 清单能发现缺口，不能制造伟大。不要用总分抵消致命问题，也不要因为脚本为绿色就宣布作品成熟。

## 一、先确认本次门控

- **对象**：场景 / 章节 / 短故事 / 全书
- **阶段**：初稿 / 结构修订 / 语言修订 / 终稿
- **用户承诺与硬边界**：
- **本轮只解决的层级**：

## 二、交付红线

任一项不成立，先修再交付：

- [ ] **存在理由**：删除本单元会造成具体因果、关系、认知或情感缺口。
- [ ] **因果变化**：重要结果来自人物选择与既有压力，不靠新设定或巧合解题。
- [ ] **人物真实**：关键行为能由目标、策略、误判和代价推导；反常处有压力依据。
- [ ] **专属经验**：至少一个场面或细节只属于这些人物与这个世界，不是通用小说腔。
- [ ] **连续性**：事实、时间、位置、知识边界、关系和世界规则与前文相容。
- [ ] **交付完整**：用户要求的篇幅、文件、正文和状态回写已真实完成。

章节默认字数遵守项目设定；标准长篇通常不少于 3000 个中文字符，快速初稿不少于 2500，短故事不少于 6000。字数只是边界，不是质量代理。

## 三、章节证据

为每项指出正文位置，不写“有 / 无”：

- **POV 欲望**：在哪个动作中可见？
- **能动阻力**：对方或环境怎样主动改变局面？
- **策略变化**：人物何时发现旧方法不够？
- **不可逆变化**：信息、关系、资源、身份、认知或承诺改变在哪里？
- **代价**：谁具体失去什么？
- **离场效果**：读者带走问题、决定、情绪落点、意象还是闭合？

不强制每章使用悬念钩子。安静章节必须改变关系、理解或下一步选择；单场景章节必须有持续压力和策略变化。

## 四、人物与对白

- [ ] 人物不是在替作者解释主题或设定。
- [ ] 对话双方各自争取东西，且至少一方保护不愿说出的内容。
- [ ] 把姓名遮住后，主要人物的目标、词汇和策略仍可区分。
- [ ] 关系变化有可观察证据，不用“信任增加”“感情加深”代替场面。
- [ ] 对手即使主角不在场，也有合理的下一步行动。
- [ ] 人物至少有一处既令人意外、回看又符合其旧策略与压力的选择。

## 五、语言与视角

- [ ] 叙事距离稳定；变化有明确效果。
- [ ] 细节来自视角人物的注意力，而非作者随机摆设。
- [ ] 抽象概括、场景呈现和必要说明各尽其职，不机械追求“全展示”。
- [ ] 强动作、物件或比喻后没有重复解释。
- [ ] 句法节奏受感知与压力支配，不是人为长短句轮换。
- [ ] 比喻来自人物经验和项目意象系统，不是廉价“文艺感”。
- [ ] 最漂亮的句子仍服务整体；不服务则删。

## 六、独创性

- **最不可替换的一处**：为什么只能发生在本作？
- **最像默认模板的一处**：主角、创伤、转折、对手或结局中的哪项？
- **被舍弃的第一反应**：原本最顺手会怎么写，最终为什么没有这样写？
- **一处勇敢选择**：作品在哪里没有替人物或作者逃避后果？

## 七、结构与结局

- [ ] 开篇建立的注意力契约在正文中持续兑现。
- [ ] 主要节点能用“因为 / 所以 / 但”连接。
- [ ] 中段改变目标、权力、认知或代价性质，而非只增加事件。
- [ ] 高潮解决办法由前文能力、关系、选择和代价共同生成。
- [ ] 结局同时处理外部结果、人物选择与情感落点。
- [ ] 主题由不同人物活出来，不由叙述者总结正确答案。
- [ ] 开篇意象 / 动作 / 场所在结尾以新意义返回，或作品有同等强度的形式闭合。
- [ ] 结尾停在余震最强处，没有为了“讲清楚”继续消耗力量。

## 八、机械工具的正确用法

1. 运行脚本，保存命中位置。
2. 回到上下文判断是真问题、体裁特征还是误报。
3. 只修改真正伤害阅读的地方。
4. 重读修改后的完整段落，防止局部指标改善、整体声音变差。

脚本可发现：字数边界、部分高频措辞、文件结构、粗略时间线与显式状态冲突。脚本不能可靠判断：主题深度、情感真实性、隐喻质量、结构必要性、人物魅力或作品是否伟大。
