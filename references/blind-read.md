# 盲读协议：看不见大纲的读者

> 任何进入可交付状态的章节或短篇，必须经过一次只看见正文的阅读。写作者的复盘不准先于读者。

## 派出方式（硬）

使用独立 subagent 或新的隔离调用。该次调用的可读文件白名单：

- 长篇：`manuscript/zh/` 本章全文；若非第 1 章，加上上一章全文。
- 短篇：该短篇文件中的 `## 正文` 区块。

禁止打开：`00-大纲.md`、`01-人物档案.md`、`05-声音锁.md`、`99-进度仪表盘.md`、`workspace/`、`04-角色沙盘/`、`02-世界观与伏笔.md`、任何任务卡 / 场景计划 / 感知包 / 复盘。

禁止同上下文填写盲读。写作 agent 不得自己写 `blind-read.md`。隔离 agent 只返回填写后的模板；写作 agent 把返回原文写入 `blind-read.md`，不改写评语。Spawn prompt 只列白名单绝对或仓库相对路径。

宿主实现见 [harness-grok-antigravity.md](harness-grok-antigravity.md)：Grok Build 用 `spawn_subagent`（优先 `blind-reader`，否则 `explore`）；Antigravity 用 `invoke_subagent`（优先 `blind-reader`）；Pi 用 `pi -p --no-context-files --no-skills`（或可选 `blind-reader` subagent 包）。不要用 git worktree 当隔离——工作树仍含大纲。

若当前宿主无法派出隔离 agent：停止交付，向用户说明，并给出“请另开一次只读这两份正文的对话”的恢复指令。不准在写作上下文里假装盲读。

## 输出

写入 `workspace/chapters/第XXX章-标题/blind-read.md`（短篇可写在同目录 `blind-read.md` 或短篇文件外的同名旁路文件；长篇必须用工作台路径）：

```markdown
# 盲读

- **我以为自己在读一个怎样的人**：
- **走神起点**：（引用原文短句；没有则写“无”）
- **我最想知道而文本没给的**：
- **不可逆变化（读者复述）**：复述不出则写“复述不出”
- **听起来像作者、不像人物的句子**：（引用；没有则写“无”）
- **是否还想翻下一页**：想 / 勉强 / 不想
- **一句话总判**：
```

禁止打分。禁止根据题材模板猜测作者意图。复述不出不可逆变化 = 盲读失败。

## 写作者在盲读之后

1. 只处理盲读提出的最高杠杆问题（走神、复述不出、作者腔）。
2. 改正文后，若曾失败，必须重新派出盲读。
3. 再写 `review.md`，其中必须有「盲读指出 / 正文改动」两行。
4. 不得把盲读失败写成“读者理解有误”。
5. 把“像作者腔”的句子追加进 `05-声音锁.md` 禁止列表；把改后仍有判断力的普通句追加进好句子（上限见声音锁模板，先进先出）。

工厂模式每 5 章抽检一次完整隔离盲读；未抽检的章节若仍写盲读文件，必须标注“未隔离”，事务验收不把它当作作者硬门。
