# 长篇章节正文模板

> 只用于 `manuscript/zh/第XXX章-标题.md`。本文件是成品稿模板，不放任务卡、场景拆分、复盘、检查报告或任何写作说明。

```markdown
第XXX章：章节标题

这里写正文第一段。

这里写正文第二段。
```

硬规则：
- 第一行只写章数和章标题。
- 第一行后空一行，再直接写正文。
- 正文中不要出现 `## 正文`、`## 本章任务卡`、`## 场景拆分`、`## 章节复盘`。
- 本章任务卡、场景拆分、沙盘裁决和复盘写入 `workspace/chapters/第XXX章-标题/`。
- 如果从旧混合章节迁移，运行 `python3 scripts/split_chapter_workspace.py novels/书名`。
