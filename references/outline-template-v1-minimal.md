## 开写门槛

- [ ] 故事承诺与主题问题不是同一句宣传语。
- [ ] 对手拥有独立目标与至少一个有效判断。
- [ ] 主要节点能由选择和后果连接，而非“然后发生”。
- [ ] 高潮解决办法在前文因果中有根。
- [ ] 至少一项人物—世界—语言组合具有专属性。
- [ ] 首章任务明确，但仍给写作发现留下空间。
