# 章节工作台模板

> 适用于 `workspace/chapters/第XXX章-标题/`。只保存创作过程；正文唯一版本写入 `manuscript/zh/第XXX章-标题.md`。

## 目录

文件结构 → 任务卡 → 场景因果链 → 角色沙盘 → 章节复盘 → 修改记录。

## 文件结构

```text
workspace/chapters/第XXX章-标题/
├── task-card.md
├── scene-plan.md
├── sandbox.md
├── review.md
└── revision-notes.md
```

## task-card.md

```markdown
# 本章任务卡

- **承接因果**：上一章哪个结果迫使本章发生？
- **章节存在理由**：删掉本章，后文具体缺少什么？
- **POV 当前追求**：
- **不愿面对 / 说出的事**：
- **能动阻力**：对方 / 环境也想要什么？
- **首选策略与策略变化**：
- **必须触碰的世界 / 关系细节**：
- **不可逆变化**：事实、关系、资源、身份、认知或承诺
- **代价**：谁失去什么？
- **悬念 / 伏笔操作**：推进、偏转、回收、保温或不处理
- **离场效果**：问题、决定、情绪落点、意象或闭合
- **不可背叛项**：
```

## scene-plan.md

不强制固定场景数。为每场写因果，而非内容摘要：

```markdown
# 场景因果链

## 场景 1：[场所 / 时间 / POV]
- **进入时已经存在的压力**：
- **人物欲望**：
- **对方 / 环境的欲望**：
- **策略 1 → 失效原因**：
- **策略 2 / 转折**：
- **获得的信息与支付方式**：
- **离场状态**：什么已经不能恢复？
- **带入下一场的因果**：因为 ___，所以 ___；但 ___。
```

单场景章节也使用同一模板，记录多次策略变化和压力升级。
