# 章节工作台模板

> 适用于 `workspace/chapters/第XXX章-标题/`。只保存创作过程；正文唯一版本写入 `manuscript/zh/第XXX章-标题.md`。

## 目录

文件结构 → 感知包 → 任务卡 → 场景因果链 → 角色沙盘 → 盲读 → 章节复盘 → 修改记录。

## 文件结构

```text
workspace/chapters/第XXX章-标题/
├── perception.md
├── task-card.md
├── scene-plan.md
├── sandbox.md
├── blind-read.md
├── review.md
└── revision-notes.md
```

## perception.md

正文只允许从本文件进入。禁止用抽象名词（真相、爱情、尊严）填唯一内容。

```markdown
# 感知包

- **POV**：
- **此刻最想保住的**：
- **进门第一眼**：（物件或声音，必须可被拍摄）
- **故意不看的**：
- **以为对方要什么**：（必须是误判，写错的那种）
- **本轮保护策略**：
- **绝不会说出口的半句**：
- **策略失败时身体先做的**：
```

缩短版（工厂 / 快写）至少保留：第一眼、误判、不肯说的半句。简单章也必须有缩短版，不能跳过。

## task-card.md

```markdown
# 本章任务卡

- **承接因果**：上一章哪个结果迫使本章发生？
- **章节存在理由**：删掉本章，后文具体缺少什么？
- **POV 当前追求**：
- **不愿面对 / 说出的事**：
- **能动阻力**：对方 / 环境也想要什么？
- **首选策略与策略变化**：
- **必须触碰的世界 / 关系细节**：
- **不可逆变化**：事实、关系、资源、身份、认知或承诺
- **代价**：谁失去什么？
- **悬念 / 伏笔操作**：推进、偏转、回收、保温或不处理
- **离场效果**：问题、决定、情绪落点、意象或闭合
- **不可背叛项**：
```

任务卡不能替代感知包。

## scene-plan.md

不强制。为每场写因果备忘，正文仍以感知包为准：

```markdown
# 场景因果链

## 场景 1：[场所 / 时间 / POV]
- **进入时已经存在的压力**：
- **人物欲望**：
- **对方 / 环境的欲望**：
- **策略 1 → 失效原因**：
- **策略 2 / 转折**：
- **获得的信息与支付方式**：
- **离场状态**：什么已经不能恢复？
- **带入下一场的因果**：因为 ___，所以 ___；但 ___。
```

## sandbox.md

深度发言的产物写入感知包。此处只记有限信息边界和导演裁决。

```markdown
# 角色沙盘与导演裁决

## 有限信息边界
- **角色 A 只知道**：
- **角色 B 只知道**：

## 自然行动
- **角色 A**：目标 / 策略 / 误判 / 不肯说的半句 / 第一眼
- **角色 B**：目标 / 策略 / 误判 / 不肯说的半句 / 第一眼

## 反抗大纲点
- 原计划哪里要求人物做不自然的事？

## 导演裁决
- **结果**：吸收 / 驳回 / 延后 / 分叉记录
- **理由**：人物一致性优先于原大纲安排；不能改“这个人不会先看见这个”
- **对后续大纲的影响**：
```
