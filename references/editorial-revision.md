## 一、先诊断，不急着改

### 1. 先做体验通读

第一次读只做边注，不编辑：

- `+` 真正被吸引、感动或惊到的位置
- `?` 不理解但愿意继续的位置
- `X` 困惑且不再信任作品的位置
- `~` 注意力下降的位置
- `!` 作品突然显出独特生命的位置

记录读者体验，不先解释作者意图。若一个设计只能靠解释才能成立，它尚未在文本中成立。

### 2. 写可证伪诊断

差诊断：“节奏不好”“人物不够立体”“AI 味重”。

有效诊断应包含位置、机制和后果：

> 第三场从得到线索到离开现场，主角没有改变目标或策略；删掉 900 字后下一场仍能无缝开始，因此它在重复确认已有信息。

一次只选最高杠杆根因。通常优先级为：

1. 作品承诺 / 主题问题
2. 因果与结局
3. 人物欲望和选择
4. 场景任务与 POV
5. 信息与节奏
6. 段落与句子
7. 字词、标点与格式

## 二、修订顺序

### 第 0 轮：建立基线

- 保存当前版本或在 `revision-notes.md` 记录范围。
- 写一句“这段原本想让读者经历什么”。
- 列出不可改变的事实、伏笔和用户要求。

### 第 1 轮：承诺与结构

检查：

- 开篇承诺的故事，正文是否真的在写？
- 主要节点能否用“因为 / 所以 / 但”连接？
- 是否有两个章节承担同一功能？
- 中段是否只增加事件，没有改变目标、权力或代价的性质？
- 高潮的解决办法是否由前文的选择、能力、关系和代价共同产生？

允许的动作：删章、并章、换序、改节点因果、提前或延后揭示。此轮不要精修句子。

### 第 2 轮：人物与关系

逐个重要节点问：

- 人物此刻要什么？为什么必须现在行动？
- 采取的策略是否来自其能力、恐惧和自我谎言？
- 是否存在更方便却不愿选择的路？不选的理由在文本中吗？
- 对手是否也在主动改变局面？
- 关系变化是否有可观察证据，而非叙述者宣告？
- 人物有没有做出令自己也意外、回看却合理的选择？

允许人物改变大纲。改变后必须重算后续因果，不能只修当前场。

### 第 3 轮：场景与 POV

每场写一行：

> 谁想要什么 → 遭遇什么能动阻力 → 改用什么策略 → 什么事实 / 决定改变了局面 → 带着什么新压力离场

若写不出，场景可能需要删除、合并或重建。再检查：

- 是否从真正有压力的位置进入，而非机械要求“晚进”？
- 视角人物最先注意的细节是否符合其身份与当下欲望？
- 信息是人物争取、误判或付出代价获得的吗？
- 安静场景是否改变关系、理解或下一步选择？
- 结尾是否在最强余韵后仍继续解释？

### 第 4 轮：世界与专属细节

圈出可以出现在任何小说中的词句：房间很整洁、眼神复杂、城市灯火通明、气氛紧张。为每处选择：删除，或换成能同时完成两项任务的细节。

优先保留能同时暴露以下两项的细节：人物判断、阶层 / 职业、关系历史、世界规则、当前风险、主题意象。不要为凑“五感”添加无意义气味和触感。

### 第 5 轮：语言与声音

检查叙事距离、动词、名词、句法、段落呼吸、对白声音和意象系统。此轮才逐句处理。详见 [style-polishing.md](style-polishing.md)。

### 第 6 轮：连续性与工具

- 对照大纲、人物档案、时间线和伏笔台账。
- 运行字数、AI 痕迹、人物、时间线等脚本。
- 逐条回看命中位置，不按分数自动改文。
- 修正文与仪表盘冲突时，以正文事实为基准，除非正文是待修错误。

## 三、章节级手术

### 可删章测试

假设整章消失，后续会缺少什么？有效答案应是具体因果：某人不知道某事、关系没有破裂、资源没有丢失、主角没做出承诺。若答案只是“氛围少了”，判断氛围是否不可替代；否则合并。

### 预期—偏转测试

列出读者在场景开始时最可能预期的结果。正文可以：

- **兑现**：但让代价超出预期。
- **偏转**：目标达成，意义却改变。
- **拒绝**：人物因性格做出另一选择。
- **延迟**：只在延迟本身制造新压力时使用。

不要为了反转而随机选最不可能的结果。好转折回看有证据，初读有惊奇。

### 解释删减测试

遇到一段解释，依次问：

1. 前面的动作 / 物件 / 对白是否已经表达？是则删。
2. 这段是必要压缩吗？是则保留并写得准确。
3. 能否让信息成为人物有代价的发现？能则改成场景。
4. 删后是否只剩含混而非余味？是则补最少必要信息。

### 勇敢一刀

每次重要修订至少尝试一个高杠杆版本：

- 删掉最漂亮却不服务整体的段落。
- 让人物承受此前被作者免除的后果。
- 把最易预期的对白换成行动、沉默或错答。
- 从对手更有道理的角度重读场景。
- 让高潮依靠旧选择而非新设定。

尝试后比较读者体验，变差则回退。勇敢不是不可逆破坏。

## 四、语言与 AI 痕迹重写

“去 AI 味”不是删除某些词，而是恢复一颗具体心智在具体环境中的选择。

### 症状与根因

| 症状 | 常见根因 | 有效重写 |
|---|---|---|
| “复杂的情绪涌上心头” | 作者没有决定人物究竟怕什么 | 明确刺激、身体反应、判断与选择 |
| 四字词和形容词堆积 | 没有可观察事实 | 找到一个承担压力的物件或动作 |
| “然而 / 与此同时 / 这意味着”过多 | 句间关系靠讲解而非场面 | 重排动作因果，删除重复结论 |
| 所有人说话完整正确 | 人物没有独立目的与风险 | 给每人隐藏目标、回避点和说话成本 |
| 段落长短过于整齐 | 句法没有受感知和压力支配 | 按注意力、动作速度和情绪阻塞重组 |
| 金句密集 | 作者替人物总结主题 | 保留最必要的一句，其余还给场景 |

### 四步重写

1. **确定意识**：这是谁在看？此刻最在意什么？
2. **确定刺激**：外界哪个具体事实触发反应？
3. **确定选择**：人物因此做、忍住或误解了什么？
4. **确定句法**：句子速度、停顿和信息顺序如何服从这次经验？

不要把“他很悲伤”机械换成握拳、低头、胸口一紧。动作也会成为新陈套；必须来自人物、场所和关系。

### 比喻检查

- 比喻来自谁的经验词库？
- 是否比字面表达更准确，而不只是更华丽？
- 是否与项目意象系统相容？
- 强比喻后是否又解释一遍？删掉解释再读。

## 五、开篇与结局

### 开篇

开篇不是必须爆炸，而是必须建立注意力契约：

- 谁在感知，什么对其不正常？
- 读者应相信这本书会关注什么？
- 哪个具体选择初次暴露人物的保护策略？
- 语言是否已经是这本书自己的语言？

可以从天气或日常开始，只要天气 / 日常正在施压、暴露人物或建立不可替代的世界。删除“不能从天气开始”之类机械禁令。

### 结局

分别验证四层：

1. **因果**：解决办法由前文生成。
2. **人物**：最终选择回应开篇的保护策略或自我谎言。
3. **主题**：不同价值的冲突被活过，不被总结成口号。
4. **形式 / 意象**：开篇元素回归，但含义已经改变。

结尾停在余震最强的位置。解释未必错误；只保留读者无法从场面获得、且确有必要的那部分。

## 六、伟大作品门控

不用数字总分。对每一项写“正文证据 / 最强处 / 最弱处 / 下一步修改”。

### 1. 独特性

作品是否拥有不可替换的人物—世界—语言组合？指出一处别的作品难以复制的场面，也指出一处仍像题材默认值的设计。

### 2. 必然性

重大事件是否由选择与后果生成？找出最强因果链和最像作者搬运的一处。

### 3. 人物复杂度

人物是否既连贯又能惊人？对手和配角是否拥有不依附主角的愿望？找出一处角色被写成工具的地方。

### 4. 结构惊奇

转折是否“初读意外，回看必然”？标出证据链；若只能靠隐藏关键信息或新设定，判定未通过。

### 5. 语言准确度

语言是否来自这个叙述意识，而非通用“小说腔”？保留一段最值得捍卫的文字，删除或重写一段最自我陶醉的文字。

### 6. 情感余震

作品是否让读者经历矛盾，而不是被告知情绪？结尾后仍在工作的物件、动作、关系或问题是什么？

### 7. 整体完成度

开篇承诺、过程升级与结尾兑现是否属于同一本书？支线、意象和节奏是否共同服务整体，还是只是各自精彩？

任何一项证据不足，都不说“已达出版级”。先做最高杠杆修改，再重新通读。

## 七、交付记录

每次修改在 `revision-notes.md` 记录：

```markdown
## YYYY-MM-DD 修订

- **范围**：
- **读者体验问题**：
- **根因诊断**：
- **本轮职责**：结构 / 人物 / 场景 / 语言 / 连续性
- **实际改动**：
- **保留未改**：
- **验证证据**：
- **下一轮最高杠杆问题**：
```

交付时区分“已修复”“仍有风险”“个人审美选择”。不要把不确定判断包装成客观错误。
