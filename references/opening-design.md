# 开篇设计：建立注意力契约

> 开篇不一定爆炸，不一定三段内冲突，也不一定以悬念结束。它必须让读者感到：这里有一颗值得跟随的意识，一个正在改变的压力，以及一种属于本书的观察方式。

## 目录

开篇任务 → 进入方式 → 信息控制 → 第一选择 → 结尾效果 → 开篇自查。

## 开篇的四项任务

### 1. 建立感知者

读者不需要立刻知道完整履历，但应开始理解：

- 谁在感知这个场面
- 此人首先注意什么、忽略什么
- 什么对其而言不正常或不可承受
- 面对压力时习惯使用什么保护策略

人物通过判断与选择站住，不靠一段性格介绍。

### 2. 建立注意力契约

让读者知道这本书会要求他们关注什么：真相、关系、劳动、权力、身体、语言、升级、冒险或某种难以命名的经验。

契约可以由危机建立，也可以由一个精确的日常动作、一段异常秩序、一个关系温差或一种独特叙述声音建立。

### 3. 建立初始失衡

开篇结束前，至少有一项不再稳定：

- 人物发现旧方法不够
- 日常中出现无法忽略的异常
- 关系权力悄悄改变
- 一个选择开始产生后果
- 读者重新解释刚刚看到的东西

失衡不等于枪声、尸体或倒计时。安静小说的失衡可能是一只没被接过的碗、一个改掉的称呼、一封没有打开的信。

### 4. 建立语言

开篇的叙事距离、细节密度、词汇来源、句法节奏和叙述态度，应已经属于这本书。不要首章靠密集修辞制造“高级感”，后文又换回通用小说腔。

## 可用的进入方式

这些是选择，不是排名：

- **行动中进入**：人物已经在处理问题，适合即时压力。
- **日常偏移**：重复动作中出现微小异常，适合现实、恐怖、关系小说。
- **结果先行**：先展示后果，再逐步揭示原因。
- **关系温差**：一句称呼、座位、钱或身体距离暴露旧历史。
- **独特劳动**：从职业动作切入，让世界规则和人物能力同时可见。
- **声音先行**：叙述意识本身足够有张力，适合第一人称或形式驱动作品。
- **环境施压**：天气、地理、建筑或人群正在改变选择，而非充当壁纸。
- **缺席中心**：通过一个没出现的人 / 物形成可感知空洞。

选择最能兑现读者契约的方式，不必追求最大声量。

## 信息控制

开篇只提供读者完成当前场面所需的信息。背景可通过以下方式进入：

- 人物为了完成动作不得不使用的知识
- 关系双方都知道却故意不说透的历史
- 规则第一次造成可见代价
- 一个具体物件携带的旧痕迹
- 必要而准确的简短概述

不要因为害怕“信息倾倒”而故意让读者无法定位。神秘来自有意义的未知，不来自缺少基本事实。

## 第一选择

开篇最好让主角做一个小而有诊断力的选择。它未必改变世界，但应暴露：

- 人物最想保护什么
- 更愿意伤害谁或牺牲什么
- 使用哪种旧策略
- 哪条未来代价已经开始生根

结局可以让同类场面再次出现，人物做出不同选择，以动作而非总结完成弧线。

## 结尾效果

首章可以用以下任一效果离场：

- 一个具体问题
- 一项已做出的决定
- 一次关系权力变化
- 一个物件获得新含义
- 一种清晰而复杂的情绪落点
- 一个完整小闭合，让读者相信作者知道何时停下

悬念钩子只在它属于作品时使用。不要用突然来电、门外脚步或“他不知道的是”给所有首章统一盖章。

## 开篇自查

- [ ] 读者能感到谁在看，以及此人为何这样看。
- [ ] 开篇已经建立本书真正关注的东西。
- [ ] 一个具体压力正在改变人物或局面。
- [ ] 主角做了能暴露保护策略的判断或选择。
- [ ] 背景信息足够定位，但没有替场面解释一切。
- [ ] 语言、细节和节奏属于本书，而非题材默认腔。
- [ ] 离场效果与作品契约相符，不是机械悬念。

最后问：如果把专有名词和人名替换掉，这个开篇是否仍可能出现在几十本小说里？如果是，重做人物注意力、具体劳动、关系证据或语言，而不是只把事件做大。
