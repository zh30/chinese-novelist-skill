# 人物档案 v3：矛盾、策略与选择

> 人物档案不是性格形容词清单，也不是命令人物永远一致的牢笼。它记录人物如何保护自己，以及压力如何迫使其做出既意外又合理的选择。

## 目录

可见的人 → 压力引擎 → 矛盾性 → 声音 → 关系 → 人物弧线 → 有限信息 → 对手检查 → 章节调用与质量检查。

## 使用方法

新项目先写主角、对手和一名关键关系人物。只填能改变场景选择的字段；未知处保留为待发现。静态核心写在本档案，章节后的动态变化写入 `04-角色沙盘/` 与进度仪表盘。

## 对手附加检查

- [ ] 即使主角不存在，对手也会继续追求自己的未来。
- [ ] 对手至少在一个关键判断上更接近真相。
- [ ] 对手的恐惧与利益可以理解，手段不必被认同。
- [ ] 高潮迫使两种活法碰撞，而不只是打倒更坏的人。

## 章节调用卡

写人物出场前只提取：

```markdown
- 此刻具体追求：
- 当前压力：
- 首选策略：
- 最可能误判：
- 不愿说出的事：
- 关系权力证据：
- 若被逼到边界，最可能做出的惊人但合理选择：
```

写完后只回写发生变化的事实：新知识、误判修正、关系证据、已支付代价和下一步倾向。不要每章重写整份档案。

## 人物质量检查

- 把姓名遮住，行动与对白是否仍能辨认其目标和策略？
- 人物是否只在主角需要时才行动？
- “反常行为”能否由压力与旧策略推导，而非作者需要？
- 关系变化是否落在钥匙、座位、称呼、钱、秘密、触碰、离开等可观察证据上？
- 人物是否至少有一处让作者不容易替其辩护，却仍能理解？
