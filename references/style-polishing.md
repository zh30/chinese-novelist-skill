# 中文小说语言：观察、距离与音乐

> 好文风不是华丽，也不是删除一组“AI 高频词”。它是一颗具体心智在具体世界中选择看什么、略过什么、怎样排列经验。

## 目录

风格宪章 → 细节 → 展示与讲述 → 情绪 → 句法 → 段落 → 对白 → 比喻与意象 → AI 痕迹 → 终稿语言轮。

## 一、先建立风格宪章

在项目中记录：

- **叙事距离**：紧贴身体、贴近意识、中距离观察或远距全知；何时变化。
- **细节偏好**：视角人物先注意价格、秩序、出口、面孔、气味、工具还是声音。
- **词汇来源**：职业、地域、教育、年龄、时代。
- **句法节奏**：常态如何呼吸，压力下怎样破坏常态。
- **叙述态度**：亲密、冷眼、温柔、讽刺、困惑或克制。
- **意象家族**：允许反复变形的 1–3 组物件 / 环境。
- **禁用捷径**：本项目最容易滑入的形容词、金句、比喻和题材腔。

“细腻、冷峻、电影感”不能单独构成风格说明，必须落实为以上选择。

## 二、让细节带着判断

不要平均扫描房间。问：这个人物此刻为什么会注意它？

一个好细节最好同时完成两项：

- 暴露人物的专业或偏见
- 显示关系历史
- 体现阶层与资源
- 让世界规则可见
- 增加当前风险
- 承载并改变核心意象

“桌上有一只杯子”通常无效；“她只给客人用缺口朝外的杯子”同时写物件、控制和关系。不要为了五感齐全添加无意义的气味与触感。

## 三、展示与讲述都要准确

“只展示，不讲述”会制造冗长动作戏。选择方式：

- **场景**：决定正在发生、关系正在改变、读者需要亲历时。
- **概述**：跨越重复、压缩时间、建立模式时。
- **直接讲述**：一个准确判断比三段表演更有力时。
- **留白**：读者已有足够证据，解释只会削弱时。

问题不在“讲述”，而在空泛和重复。强场面后若紧跟“这说明他很悲伤”，先删解释再读。

## 四、情绪从刺激到选择

改写抽象情绪时依次确定：

1. 外界什么具体事实触发了人物？
2. 人物如何理解或误解它？
3. 身体与注意力发生什么变化？
4. 人物做、忍住或说错了什么？

不要把所有情绪都换成握拳、心跳、低头、胸口一紧。动作必须属于这个人物和这段关系。

## 五、句法服从意识

- 人物注意力高速跳转时，句子可短促、截断或省略。
- 人物试图控制局面时，句子可能过度完整、分类、延迟核心动词。
- 创伤、醉意、疾病和恐惧会改变感知顺序，但不要把含混当深度。
- 安静不等于长句；动作不等于短句。先确定经验，再选择节奏。

朗读段落，标出无意的重复拍点。改变信息顺序和句法重心，不机械轮换长短句。

## 六、段落是一组注意力

新段落通常意味着至少一项变化：说话者、动作主体、注意对象、时间、空间、策略或情绪重心。关键句可以独立成段，但若每句都独立，力度会被稀释。

段尾是压力位置。把最重要的名词、动作或认知放在段尾附近；强段落后不要补一句解释。

## 七、对白是一场交易

每个说话者同时拥有：想得到的东西、不愿暴露的东西、说错话的成本。对白可以完成任务，也可以故意逃避任务；不能所有人都完整、正确、漂亮。

区分声音主要靠：

- 词汇来自哪里
- 句子如何组织
- 面对权力时怎样改变
- 用什么策略回避
- 哪些内容用动作代替

口头禅只能点缀，不能代替人物逻辑。删去姓名与标签后，读者应能从目标和策略大致辨认说话者。

## 八、比喻与意象

使用比喻前问：

- 这是谁会想到的比较？
- 它是否比字面更准确？
- 它是否属于项目意象家族？
- 它是在推进感知，还是展示作者会写？

一个强比喻胜过一串弱比喻。意象先在场景中作为真实物件发挥作用，再逐次改变含义；不要由叙述者宣布“它象征着”。

## 九、AI 痕迹的根治

常见表面症状包括空泛情绪、四字词堆积、解释连接词、整齐排比、所有人物同声、过密金句和均匀句长。脚本只能标记部分症状。

有效修订不是同义词替换，而是重建四层：

1. **意识**：谁在看，最在意什么？
2. **刺激**：外界哪个事实进入意识？
3. **选择**：人物因此做或不做什么？
4. **句法**：语言如何服从这次经验？

若段落仍然通用，删掉专有名词再读。任何小说都能使用的观察，要么删除，要么压回人物的职业、身体、关系和所在场所。

## 十、终稿语言轮

按顺序执行，避免同时改乱：

1. 统一 POV 与叙事距离。
2. 删除重复结论和解释尾巴。
3. 把通用细节换成有双重任务的准确细节。
4. 校准每个主要人物的说话策略。
5. 收拢随机比喻，强化少量意象家族。
6. 朗读，修复无意节拍、拗口和段落重心。
7. 保留必要的粗粝、不对称和人物口气；不要把所有句子磨成同一种“漂亮”。

最后选两段：一段最值得捍卫，一段最自我陶醉。解释为什么前者属于这本书，删改后者再通读。
